# EssayBridge - 논술 첨삭 및 컨설팅 플랫폼

대학 입시 논술 첨삭, 온라인 강의, 입시 컨설팅을 한 곳에서 제공하는 통합 플랫폼입니다.

## 🎯 주요 기능

### 1. **논술 첨삭 서비스**
- 전문가의 상세한 논술 첨삭
- 48시간 내 첨삭 완료 보장
- AI 기초 첨삭 기능
- 첨삭 히스토리 관리
- PDF 다운로드 지원

### 2. **온라인 강의**
- 대학별 맞춤 논술 강의
- 서울대, 연세대, 고려대 등 주요 대학 커리큘럼
- 논술 기초부터 고급까지 단계별 학습
- 무제한 수강 (구독 플랜)

### 3. **입시 컨설팅**
- 1:1 맞춤 입시 상담
- 대학 선택 전략 수립
- 모의 면접 진행
- 학습 멘토링

### 4. **커뮤니티**
- 합격 후기 공유
- Q&A 게시판
- 대학별 게시판
- 익명 게시 옵션

### 5. **유료 서비스 플랜**

#### 프리 플랜 (무료)
- 기본 강의 3개 무료 수강
- 커뮤니티 이용
- AI 기초 첨삭 (월 1회)

#### 베이직 플랜 (99,000원/월)
- 전문가 논술 첨삭 (월 3회)
- 모든 강의 무제한 수강
- 1:1 컨설팅 (월 1시간)
- 학습 진도 관리

#### 프리미엄 플랜 (199,000원/월)
- 전문가 논술 첨삭 (월 10회)
- 모든 강의 무제한 수강
- 1:1 컨설팅 (월 3시간)
- 모의 면접 (월 2회)
- 24시간 질의응답
- 합격 전략 리포트

## 🛠️ 기술 스택

- **Frontend**: React 18 + TypeScript
- **Styling**: Tailwind CSS
- **상태관리**: Context API
- **라우팅**: React Router v6
- **아이콘**: React Icons
- **빌드 도구**: Vite

## 🚀 시작하기

### 설치

```bash
npm install
```

### 개발 서버 실행

```bash
npm run dev
```

개발 서버는 http://localhost:5173 에서 실행됩니다.

### 프로덕션 빌드

```bash
npm run build
```

### 빌드 미리보기

```bash
npm run preview
```

## 🔐 인증 시스템

현재 MVP 버전은 로컬 스토리지 기반의 간단한 인증을 사용합니다.
프로덕션 환경에서는 다음과 같은 개선이 필요합니다:

- JWT 토큰 기반 인증
- OAuth 2.0 소셜 로그인
- 서버 사이드 세션 관리
- HTTPS 필수

## 💳 결제 시스템

현재 버전은 결제 UI 시뮬레이션만 제공합니다.
실제 결제 연동을 위해서는:

- 아임포트 또는 토스페이먼츠 연동
- PG사 계약 및 설정
- 결제 보안 강화
- 영수증 발급 시스템
